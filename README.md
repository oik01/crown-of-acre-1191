# ⚔️ Crown of Acre: 1191 — 3D Crusader Mounted & Tactical Action Game

**Play Live in Your Browser (Desktop & Mobile, 60 FPS):**  
👉 **[https://oik01.github.io/crown-of-acre-1191/](https://oik01.github.io/crown-of-acre-1191/)**

Built with **Three.js (WebGL2)** and the **Web Audio API** using a multi-agent **Plan $\rightarrow$ Parallel Build $\rightarrow$ Independent Visual & Gameplay Audit $\rightarrow$ Improve $\rightarrow$ Rebuild** workflow.

---

## 🎮 Key Features
- **Zero-Placeholder Procedural 3D Art**:
  - Sculpted 12th-century Great Helms (recessed ocular slits, 24 ventail breathing perforations, riveted gilded-brass crosses, chainmail coifs), heraldic surcoats, articulated pauldrons/couters/poleyns, heater shields, broadswords, and couched lances.
  - Contoured medieval Destrier warhorses with steel chanfron faceplates, flowing manes/tails, heraldic caparison barding, high-cantle saddles, stirrups, dynamic reins, and 4 three-segment articulated legs driven by phase-offset 4-beat gallop gaits.
  - Contemporaneous Allied Crusaders (Infantry, Crossbowmen, Elite Plumed Companions) vs. Saracen / Seljuk Forces (Turbaned Spangenhelms, Gilded Lamellar Armor, Round Brass-Bossed Shields, Scimitars, Composite Bowmen, and Emir Al-Kamil).
- **Seamless Mounted & Dismounted Combat**:
  - Press **`E`** at any time to vault off your warhorse onto foot (or whistle to summon and remount your steed).
  - **Mounted**: High-momentum cavalry steering, Couched Lance Gallop Charges (`Space`), sweeping horseback broadsword slashes (`Left Click`), and shield arrow deflection.
  - **On Foot**: Snappy 3-hit directional sword combos (`Left Click`), Shield Bash & Block (`Shift` / `F` / `Right Click`), and agile Dodge-Rolls (`Space`).
- **Companion Retinue Tactical Redirection (`1`–`4`)**:
  - **`[1]` Follow Wedge**: Protective V-formation around your knight
  - **`[2]` Charge Target**: All-out lance/melee assault on the target zone ahead
  - **`[3]` Shield Wall**: Interlocking defensive line with 70% armor buff
  - **`[4]` Hunt Archers**: Flank and eliminate Saracen composite bowmen on the ridges

## 🕹️ Controls

| Action | Desktop (Keyboard + Mouse) | Mobile / Touch |
| :--- | :--- | :--- |
| **Move & Turn (Bound Camera)** | `W / S` & `A / D` (or Arrow Keys) | Left Virtual Thumbstick |
| **Free-Look 360° (Unbind Camera)** | Hold `Right-Click` & Drag (or press `C`) | Top-Right `🔒 Cam` Toggle |
| **Primary Attack (Slash / Combo)** | `Left Click` | `⚔️ SLASH` Button |
| **Couched Lance Charge / Dodge-Roll** | `Space` | `🏇 CHARGE` Button |
| **Shield Block / Shield Bash** | `Shift` / `F` / `Right Click` | `🛡️ SHIELD` Button |
| **Mount / Dismount / Whistle** | `E` | `🐎 MOUNT` Button |
| **Companion Tactical Orders** | `1`, `2`, `3`, `4` | Bottom Tactical Command Bar |
| **Pause / Resume** | `P` or `Esc` | Top-Right `⏸ Pause` Button |
